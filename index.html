关于这份档案

本测试使用 Open Extended Jungian Type Scales 1.2（OEJTS）第一部分的 32 道词对题，该量表由 Eric Jorgenson 于 2014 年公开发表，作为 MBTI 的开源替代量表，在 Open-Source Psychometrics Project 的对照研究中表现最优。

重要提示

MBTI 与 OEJTS 均非临床诊断工具，结果仅供自我探索与娱乐参考。人格是连续谱，不是四个格子。请把结果当作一面镜子，而不是一张判决书。

图像来源

历史人物肖像取自 Wikimedia Commons 的公有领域或自由许可文件，统一处理后用于人物对照。人物与类型的对应为基于公开传记的推断，非实证结论。
